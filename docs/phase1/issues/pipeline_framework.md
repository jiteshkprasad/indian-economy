# pipeline_framework: Phase 1 issues and deviations from STACK_AND_REPO.md

| # | Severity | Issue | Impact / what was done | Status |
|---|---|---|---|---|
| fw-1 | minor | **Raw pins are one file per unit** (`data/raw_pins/<unit>.yaml`), not one shared `data/raw_pins.yaml` as the Phase 1 brief says. | Ten ingest agents writing one YAML file at the same time would race and conflict. The manifest's `raw_pins` section gives the combined view. | DECISION NEEDED (orchestrator) |
| fw-2 | minor | **New mechanism: `data/registry_additions/<unit>.yaml`.** Agents may register a source they need without editing `data/registry.yaml`. The loader merges it; entries must be `unverified`; id collisions are errors. | Unblocks parallel agents. The orchestrator must verify additions and merge them into `registry.yaml` and `SOURCES.md`. | DECISION NEEDED (orchestrator) |
| fw-3 | major | **`just fetch-archive` / raw archive not implemented.** The archive location is still an open owner question (STACK_AND_REPO §9 Q3), and the owner is unavailable. | On a fresh clone, `fetch` re-downloads and checks the bytes against the pins; if upstream changed, it records a revision. Exact repro therefore depends on upstream files staying available. | OPEN: owner |
| fw-4 | major | **No Linux CI yet**, which the design names as the authoritative build. | `repro` was run on Windows only: byte-identical across two builds and two hash seeds. Linux behaviour is unverified. | OPEN (needs GitHub repo; STACK_AND_REPO §9 Q1) |
| fw-5 | minor | Package is `pipeline/core/` (per the Phase 1 brief), not `pipeline/common/` (design §7). Stages for SAM assembly come in Phase 2. | INFO |
| fw-6 | minor | Provenance omits `code_hash` and licence (design §1.7), and there is no separate `lineage.parquet`. | `code_hash` in every provenance row would change every file on any code edit; it lives in `data/manifest.json`. Licence is looked up from the registry by `source_id`. Lineage for derived/estimated rows is the `inputs` column (comma-separated `prov_id`s). Provenance is per unit (`data/clean/<unit>/_provenance.parquet`), not one global file. | INFO |
| fw-7 | minor | Added `PYTHONUTF8=1` and `PYTHONIOENCODING=utf-8` to the pinned environment. | The Windows console (cp1252) crashed printing polars tables and Hindi/₹ text. | RESOLVED |
| fw-8 | minor | `docs/phase0/GAP_MAP.md` had CRLF line endings in the working tree (git's index copy is LF). | Normalised to LF; git shows no content change. The new line-ending test would otherwise fail. | RESOLVED |
| fw-9 | minor | ISSUES.md Phase 0 raw log (mospi_nas verifier) says pipelines "must not spoof browsers". | fw-16 | minor | **Raw path now includes the unit**: `data/raw/<source_id>/<date>[-rN]/<unit>/<name>`.
