## Fixer run (verifier findings V1-01, V1-03, V5-04)

- **V1-01 (fixed at the source).** `pipeline/sam/run.py` writes `balancing_log.pct_change` as a percent (`100 x change / |prior|`); `sam_export.entries_json` copied it unchanged while the contract, the fixture and the panel (`<Num fmt="pct">`) treat it as a fraction, so the real map showed every move 100x too large (HH--PRDS "-4.4%" for a -0.044% move). The exporter now writes `pct_change / 100`, and `entries.schema.json` states the unit ("fraction of the prior: (v - prior) / |prior|"). The fixture's synthetic log now stores percent like the real log (so the same writer line serves both), and a fixture bug was fixed on the way: `fixed` entries had prior = balanced but a non-zero `pct_change`. New tests: `test_identities.py::test_entry_pct_change_is_a_fraction` (real and fixture: pct_change = (v - prior)/|prior| within the slack of the 2-dp rounding of v and prior) and `::test_entry_pct_change_matches_balancing_log` (real: every entry equals the log's percent / 100 within 1e-6).
- **Note for the orchestrator (owner of `tests/verify/`):** `tests/verify/test_phase3_data_fidelity.py::test_entry_pct_change_is_a_fraction` will still fail (so it stays XFAIL, not XPASS) after this fix, for a reason in the test, not the data: it recomputes `(v - prior)/|prior|` from the exported 2-dp values with an absolute tolerance of 1e-3, and 21 entries with |prior| between 1 and 10 crore differ by more than that only because of that rounding (e.g. E_BANK<-E_INSP R8: prior 1.87, v 1.62 (rounded), exported -0.137291, recomputed -0.133690; the unrounded log gives -0.137291). The other 3,805 checked entries agree. A tolerance of `1e-6 + 0.0101 * (1 + |want|) / |prior|` (the rounding bound) passes all 3,826; `test_entry_pct_change_matches_balancing_log` checks the same thing exactly against the parquet.
- **V1-03 / V5-04 (fixed in the export; display needs U3, types need U2).** Root cause on U1's side: `summary.headline.hh_outlays.parts` carried only `split_label`, and U1's own request told U3 to show split badges only.
